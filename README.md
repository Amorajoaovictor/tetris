# Tetris Game

A fully functional Tetris game built with HTML5, CSS3, and JavaScript.

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. Use the controls to play:

## Controls

- **← →** : Move piece left/right
- **↓** : Speed up piece fall
- **↑** : Instant drop (hard drop)
- **Space** : Rotate piece
- **C** : Hold current piece

## Features

- Classic Tetris gameplay with all 7 tetromino shapes
- Hold piece functionality (press C to save a piece for later)
- Next piece preview
- Score tracking
- Line clearing mechanics
- Responsive controls
- Beautiful gradient design

## Scoring

- Lines cleared award points
- Hard drops give bonus points
- Clear multiple lines at once for combo bonuses

Enjoy playing Tetris!
